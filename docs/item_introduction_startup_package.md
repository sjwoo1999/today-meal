# 아이템 소개: 오늘한끼 (TodayMeal)

> **AI 기반 역추산 식단 관리 플랫폼**  
> "찍자마자 삐링! 바로 다음 끼니 추천까지"

---

## 1. 아이템 개요

### 1.1 서비스 정의
**오늘한끼**는 AI 이미지 인식 기술을 활용하여 사용자가 섭취한 음식을 자동으로 분석하고, **역추산 알고리즘**을 통해 남은 끼니에 무엇을 먹어야 하루 영양 목표를 달성할 수 있는지 실시간으로 추천하는 **스마트 식단 관리 서비스**입니다.

### 1.2 핵심 가치 제안 (Value Proposition)
| 구분 | 기존 서비스 | 오늘한끼 |
|------|-----------|---------|
| **기록 방식** | 수동 검색/입력 (평균 2-3분) | 사진 촬영 즉시 자동 인식 (3초) |
| **제공 정보** | 과거 섭취 데이터 조회 | 미래 식사 선제적 추천 |
| **사용자 액션** | "오늘 뭘 먹었지?" (회고형) | "다음 끼니 뭐 먹지?" (계획형) |
| **구매 연결** | 없음 | 근처 식당/편의점 메뉴 바로 연결 |

### 1.3 슬로건
> **"한 끼가 쌓여 당신의 건강이 됩니다"**

## 2. 아이템의 필요성

### 2.1 문제 정의 (Pain Points)

#### 🎯 타겟 고객의 핵심 고민
1. **"뭘 먹어야 할지 모르겠어요"** (결정 피로)
   - 하루 평균 35,000번의 의사결정 중 식사 선택이 가장 빈번
   - 건강과 맛 사이에서 매번 타협

2. **"기록이 너무 귀찮아요"** (행동 장벽)
   - 기존 앱: 음식 검색 → 양 입력 → 시간 선택 (평균 2분 30초)
   - 3일 이상 지속률 23% 미만

3. **"먹은 거 알아도 다음에 뭘 먹어야 할지 모르겠어요"** (냉대되는 데이터)
   - 칼로리 기록만으로는 행동 변화 유도 실패
   - "그래서 뭘 어쩌라고?" 문제

### 2.2 시장 기회

#### 📊 국내 다이어트/헬스케어 시장 규모
| 연도 | 시장 규모 | 성장률 |
|------|----------|-------|
| 2023 | 4.2조 원 | - |
| 2024 | 4.8조 원 | 14.3% |
| 2025 (예상) | 5.5조 원 | 14.6% |
| 2028 (예상) | 8.0조 원 | CAGR 12.5% |

#### 🔍 1인 가구 증가에 따른 수요
- 2024년 기준 1인 가구 750만 가구 (전체 35%)
- 외식/배달 의존도 높음 → 영양 불균형 우려
- **"간편하면서도 건강한 식사"** 니즈 급증

## 3. 아이템의 차별성

### 3.1 핵심 차별화 요소

#### ① 역추산(Reverse Calculation) 알고리즘
```
[기존 앱] 아침 + 점심 = 지금까지 섭취량 (과거 지향)
[오늘한끼] 하루 목표 - (아침 + 점심) = 저녁에 먹어야 할 것 (미래 지향)
```

**예시:**
> 🍚 아침: 김치볶음밥 (550kcal, 단백질 12g)  
> 🍜 점심: 된장찌개 정식 (620kcal, 단백질 25g)  
> 📊 하루 목표: 2,000kcal, 단백질 80g  
> ✅ **저녁 추천**: "단백질 43g 더 필요해요! 편의점 닭가슴살 도시락은 어때요?"

#### ② AI 즉시 인식 (찍자마자 삐링!)
- **Google Gemini Vision API** 활용
- 일반 음식: 인식률 92% 이상
- 편의점 상품: 바코드/라벨 인식으로 99% 정확도
- 평균 인식 시간: **1.8초**

#### ③ 행동으로 연결되는 추천
- 단순 "칼로리 초과" 경고 ❌
- **구체적 메뉴 + 구매처 연결** ✅
  - 근처 편의점 상품 바로 구매
  - 배달앱 연동 (추후)
  - 레시피 추천 (추후)

#### ④ 게이미피케이션 & 소셜
- 연속 기록 스트릭 (Streak)
- 주간 미션 & 뱃지 시스템
- 친구/가족과 함께하는 "스쿼드" 챌린지

|------|------|

3. **운동 루틴이 있는 피트니스 유저**
4. **당뇨/고혈압 등 질환 관리 필요 고객** (B2B 헬스케어 연계)

## 6. 핵심 기술

### 6.1 기술 스택
| 영역 | 기술 |
|------|------|
| **Frontend** | Next.js 14, React, TypeScript, Tailwind CSS |
| **AI/ML** | Google Gemini 1.5 Flash (Vision API) |
| **Backend** | Supabase (Auth, DB, Storage) |
| **Algorithm** | 역추산 영양 매칭 알고리즘 (자체 개발) |
| **Database** | PostgreSQL (Supabase), 한국 음식 DB 10,000+ |

### 6.2 기술적 차별점

#### AI 음식 인식 파이프라인
```
📷 사진 촬영
    ↓
🤖 Gemini Vision 분석
    ↓ (1.8초)
📊 영양정보 추출 + 신뢰도 점수
    ↓
🧮 역추산 알고리즘
    ↓
🍽️ 다음 끼니 추천 + 구매처 연결
```

#### 한국 특화 음식 DB
- 한식 5,000개+
- 편의점 상품 2,000개+ (GS25, CU, 세븐일레븐, 이마트24)
- 프랜차이즈 메뉴 1,500개+
- 지속적 DB 확장 (크라우드소싱 + 제휴)
